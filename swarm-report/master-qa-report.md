## Находки и где проблема
- **S5 — удаление через UI ушло в API-fallback** (сценарий всё равно PASS, мусора не осталось).
  - Что: после «Подключить» проект `octocat/Hello-World` появился в списке, но кнопка «Удалить»
    (рендерится только для статусов `ready`/`error`, см. `ProjectsPanel.tsx:277,291,303`) не стала
    видимой в окне ожидания → сработал API-cleanup `DELETE /api/projects/{id}`.
  - Предполагаемое место / гипотеза (**не установлено точно**): репо из одного README мог
    индексироваться в 0 code-чанков или дольше окна ожидания; статус не дошёл до `ready` с видимой
    кнопкой. Требует отдельной проверки, если нужен UI-путь удаления только что созданного проекта.
  - Это **не баг продукта** по имеющимся данным; escalation в P2 не требуется, но стоит подтвердить,
    что крохотный валидный репо доходит до `ready` за разумное время.
