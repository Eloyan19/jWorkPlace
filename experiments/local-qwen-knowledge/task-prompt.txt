ЗАДАЧА: заменить авто-пометку «изучено» на ручной выбор пользователя.

Сейчас при открытии панели «О проекте» ВСЕ новые концепты авто-помечаются известными
(SummaryPanel вызывает markSummaryRead → POST /api/knowledge/projects/{id}/read → db.mark_concepts_known).
Это плохо: пользователь ещё не изучил, а концепт уже «знакомый».

Нужно сделать так:
1. На каждом концепте в списке «Новое для вас» — кнопка «Изучено». По клику: пометить ЭТОТ ОДИН
   концепт известным на backend и ОПТИМИСТИЧНО перенести его из «Новое для вас» в «Уже знакомо»
   без перезагрузки всей выжимки (не терять раскрытые детали/скролл остальных).
2. Рядом с заголовком «О проекте» — кнопка «Очистить базу знаний». По клику: window.confirm, затем
   мягкий сброс на backend (все концепты снова known=0, строки concepts и связи project_concepts
   НЕ удалять), после успеха — перезагрузить выжимку.
3. Backend: добавить два эндпоинта в knowledge.py:
   - POST /api/knowledge/concepts/{slug}/known — пометить ОДИН концепт по slug (вернуть 404 если slug нет).
   - POST /api/knowledge/concepts/reset — мягкий сброс всего каталога.
   И две функции в db.py: mark_concept_known(slug) и reset_known_catalog(). Авто-пометку при открытии
   (POST /read + auto-вызов markSummaryRead во фронте) убрать.
4. Концепту нужен slug в DTO: прокинь slug в get_project_concepts (SELECT) и в render.py (new_concepts).
   Таблица concepts имеет колонку slug (см. list_known_concepts).

----- backend/app/db.py (релевантные функции) -----
def get_project_concepts(project_id: str) -> list[sqlite3.Row]:
    """Концепты проекта + их project-scoped раскрытие, джойном на глобальный каталог."""
    with get_conn() as conn:
        return conn.execute(
            "SELECT pc.concept_id AS concept_id, c.name AS name, c.category AS category, "
            "c.description AS description, c.known AS known, pc.detail AS detail, "
            "pc.evidence AS evidence "
            "FROM project_concepts pc JOIN concepts c ON c.id = pc.concept_id "
            "WHERE pc.project_id = ?",
            (project_id,),
        ).fetchall()

def mark_concepts_known(project_id: str) -> None:
    """Пометить все концепты этого проекта известными (авто при открытии панели выжимки)."""
    with get_conn() as conn:
        conn.execute(
            "UPDATE concepts SET known = 1, known_at = COALESCE(known_at, datetime('now')) "
            "WHERE known = 0 AND id IN (SELECT concept_id FROM project_concepts WHERE project_id = ?)",
            (project_id,),
        )

def list_known_concepts() -> list[sqlite3.Row]:
    with get_conn() as conn:
        return conn.execute(
            "SELECT slug, name, category, description, known_at FROM concepts "
            "WHERE known = 1 ORDER BY known_at"
        ).fetchall()

----- frontend/src/api.ts (текущая функция) -----
export async function markSummaryRead(projectId: string): Promise<{ ok: true }> {
  const res = await fetch(`/api/knowledge/projects/${projectId}/read`, {
    method: 'POST',
    headers: authHeaders(),
  })
  if (!res.ok) {
    throw new Error(await readErrorMessage(res))
  }
  return (await res.json()) as { ok: true }
}
